# Infinity Stone Ontology

```text
KERNEL
  constitutional invariants and authority boundaries

STONE
  versioned reversible specialization package
  = domain + skills + protocols + judgment + interfaces + boundaries + tests

UPGRADE
  cross-stone modifier that changes execution method without owning a domain

INVOCATION
  sentence or alias that selects a stone, upgrade, or gauntlet

GAUNTLET
  deterministic composition of stones and upgrades for a mission

RECEIPT
  immutable evidence describing what was loaded, tested, and concluded
```

A sentence may summon a stone. A skill may inhabit a stone. A protocol may govern a
stone. None of those alone is the stone.
