# Stone Authoring Standard

A candidate does not enter the canonical registry until it declares:

- stable identity, semantic version, domain, and status;
- owned and excluded responsibilities;
- activation aliases and one compressed core law;
- decomposed skills and ordered protocols;
- governing laws and judgment priority;
- typed inputs, outputs, and required tools;
- forbidden behavior and human-control triggers;
- compatible and incompatible stones and upgrades;
- positive, boundary, refusal, composition, and regression tests;
- exact receipt path and promotion rule;
- reversible runtime behavior.

## Promotion ladder

```text
IDEA -> PRACTICED -> SPECIFIED -> TESTED -> COMPOSED -> VERIFIED -> RELEASED
```

No stage may be inferred from naming quality, prompt length, or prior conversational success.
