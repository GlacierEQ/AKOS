# AKOS Thought Process Pattern

Status: Active Draft
Version: 0.1.0
Created: 2026-07-07

## Purpose

This document defines the reusable reasoning and execution pattern for AKOS work.

## Pattern

Analyze -> Research -> Select -> Design -> Implement -> Validate -> Document -> Record

## Analyze

Define the problem, object, goal, constraints, and success criteria.

## Research

Gather relevant context, sources, prior decisions, and existing artifacts.

## Select

Choose the best path based on evidence, constraints, and current system state.

## Design

Define the structure before execution.

## Implement

Make the smallest useful change that advances the system.

## Validate

Check the result against source, contract, and Pro-Code gates.

## Document

Explain what changed and why.

## Record

Update state, ledger, or handoff so the next cycle starts cleanly.

## Rule

Do not skip from analysis to implementation when source, identity, or boundary is unclear.
