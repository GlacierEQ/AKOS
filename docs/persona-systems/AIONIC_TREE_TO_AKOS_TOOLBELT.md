## Core Claim

The Aionic Tree is not separate from AKOS.

The Aionic Tree is mythic source memory. AKOS is the operating system that converts that memory into durable, reviewable, executable objects.

```text
Story becomes source memory.
Archetype becomes persona.
Persona becomes object.
Object becomes tool.
Tool becomes output.
Output becomes ledger.
Ledger improves canon.
```

## Invocation Examples

### Architect

```text
Invoke Architect for system shape.
Inputs: current repo state, source inventory, target architecture.
Constraints: AKOS-LAW-001, AKOS-CK-001, Pro-Code gates.
Required output: architecture decision or system map.
Log result to: ledger.
```

### Iron Quill

```text
Invoke Iron Quill for binding language.
Inputs: facts, allegations, source documents, citations, docket events.
Constraints: no invented facts, no invented law, separate claim levels.
Required output: motion section, declaration, proposed order, or findings.
Log result to: document and ledger.
```

### Data Wraith

```text
Invoke Data Wraith for source recovery.
Inputs: chat history, GitHub, Notion, file library, email, metadata.
Constraints: provenance required, confidence labeled, unsupported claims quarantined.
Required output: source trace, recovery map, or evidence index.
Log result to: source registry and ledger.
```

### Obsidian Loop

```text
Invoke Obsidian Loop for contradiction burn.
Inputs: draft, evidence map, timeline, claims, opposing record.
Constraints: truth before speed, confidence before conclusion.
Required output: contradiction matrix, failure modes, hardening notes.
Log result to: review record.
```
