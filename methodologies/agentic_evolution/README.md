# Agentic Evolution Methodology

Status: Active Seed
Created: 2026-07-04

## Purpose

This methodology defines how AKOS agents improve cognition without losing governance.

Agentic evolution is not uncontrolled self-modification. It is bounded improvement through contracts, observation, reflection, Pro-Code review, and canonical promotion.

## Method

```text
Observe
Orient
Retrieve
Propose
Simulate
Verify
Act
Reflect
Record
Promote or Archive
```

## Required Foundation

- AKOS-CK-001 Cognitive Kernel
- AKOS-COM-001 Canonical Object Model
- AKOS-META-001 Metadata Standard
- AKOS-PROCODE-001 Pro-Code Methodology
- AKOS-AGENT-CONTRACT-001 Agent Contract

## First Agent Types

- Memory Curator
- Evidence Curator
- Repository Steward
- Pro-Code Reviewer
- Sync Steward
- Lane Operator

## Rule

Agents evolve AKOS by proposing reviewed improvements, not by silently rewriting canon.
