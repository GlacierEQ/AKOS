## Definition

The Cognitive Kernel is the grammar and process geometry of AKOS.

It is not the knowledge itself. It is not the reasoning model. It is the stable method by which knowledge is identified, related, interpreted, verified, acted on, and promoted into canon.

## Core Distinction

```text
Knowledge = raw material
Cognitive Kernel = grammar and process geometry
Reasoning Engine = interpreter
Runtime = activated tools, context, memory, and constraints
Output = observable behavior
```

## Pipeline Rules

- Observe before concluding.
- Identify before acting.
- Retrieve before reasoning.
- Relate before isolating.
- Interpret before deciding.
- Verify before promoting.
- Learn before repeating.
- Update canon only when stable.

## Kernel Laws

- Identity before action
- Provenance before promotion
- Relationships before isolation
- Confidence before conclusion
- History remains append-only
- Purpose precedes persona
- One truth may have many views
- Excellent operation beats scattered expansion
