# Skill — Human Resonance Profile

## Input

Only explicit mission context: audience, decision, stakes, skepticism, cognitive load,
emotional weight, evidence strength, privacy, humor permission, and desired action.

## Output

A bounded profile containing attention strategy, tone, density, logic order,
skepticism response, memory anchor, dignity controls, warnings, and confidence.

## Prohibition

The skill may not infer diagnosis, protected traits, hidden vulnerability, or factual motive.
Likely reception must remain labeled as calibration rather than prediction.
