# Resume Master Stone

**ID:** `stone-resume-master`  
**Status:** `CANDIDATE`  
**Evidence target:** repository-local `TEST`

Resume Master owns the canonical resume fact graph and the controlled production of human, ATS, machine, and artifact projections. It is not a copywriting persona. It is a truth-and-release system.

## Core Contract

```text
sources -> canonical facts -> evidence states -> approved claims
        -> audience projection -> artifacts -> render verification
        -> hashes -> release receipt
```

The latest canonical package must be located before any rewrite begins. Dates, titles, metrics, artifact identifiers, limits, and non-affiliation language are invariant. PSYSOC-X may change sequence and density but cannot change claim eligibility.

## Resource Surface

- `personas/personas.json` — Resume Architect, Recruiter Signal Editor, ATS Integrity Engineer, and Evidence Auditor.
- `skills/SKILLS.md` — reconciliation, claim binding, ATS serialization, rendering, and receipt skills.
- `resources/casey-barton.resume-master.v18.json` — the first canonical candidate fact graph.
- `tools/tools.json` — bounded tool contracts.
- `connectors/connectors.json` — source, artifact, role-context, and rendering connector policy.
- `templates/` — human and ATS master projections.
- `tests/cases.json` — refusal, invariance, projection, and artifact cases.
