# Web Design Pro Skills

## 1. Recruiter Information Architecture
Answer role, value, proof, and next-action questions in the first screen. Place deeper evidence behind progressive disclosure rather than forcing every reader through the full technical ledger.

## 2. Design Token Engineering
Define typography, spacing, radii, surfaces, borders, accents, states, and responsive breakpoints as machine-readable tokens. Do not scatter unexplained values across templates.

## 3. Responsive Resume Layout
Use mobile-first flow, readable line lengths, flexible grids, and content-order invariants. Reflow must not hide evidence states or separate labels from their claims.

## 4. Semantic HTML Architecture
Use landmarks, headings, lists, links, and tables according to meaning. The page must remain understandable without CSS and without JavaScript.

## 5. Accessibility-First Design
Check keyboard navigation, focus visibility, contrast, zoom, text spacing, reduced motion, descriptive links, and meaning independent of color. Do not claim certification from a limited audit.

## 6. SEO and Social Metadata
Publish canonical URL, concise description, structured title, Open Graph metadata, and machine discovery files without inventing authority or affiliation.

## 7. Zero-Script Progressive Enhancement
Default to static HTML and CSS. Add client behavior only when it creates a bounded user benefit that cannot be delivered semantically.

## 8. Static Release Verification
Verify preview and production separately. Check all canonical routes, artifact downloads, content types, source headers, hashes, security headers, scripts, trackers, and failure routes.
